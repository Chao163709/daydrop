# 日点 · Daydrop

**把待办放在桌面上，让今天的安排一眼可见。**

日点是一款面向学生和办公人群的桌面待办与日历浮窗。不用时，它是桌面上的一颗日期圆点；悬停或点击展开，就能记录任务、查看日程、调整计划。

无需注册账号，数据默认保存在本机。

[功能介绍](#功能介绍) · [开始使用](#开始使用) · [本地开发](#本地开发) · [反馈问题](https://github.com/Chao163709/daydrop/issues)

> 当前版本：**0.1.0 · 早期开发版**。Windows 已完成编译与安装包构建，部分系统交互仍待实机验收；macOS 尚未实机验证。当前尚未在 Releases 发布安装包，可先从源码运行。

## 功能介绍

### 随手展开，用完收起

- 小圆点显示日期与未完成任务数量，可拖动、吸附屏幕边缘。
- 支持悬停展开、点击展开与固定展开；移开鼠标、失焦或按 Esc 收起。
- 可置顶、隐藏到系统托盘，通过全局快捷键唤回。
- 半透明毛玻璃面板，支持浅色、深色和跟随系统；可调整强调色、透明度与宽度。

### 任务有记录，计划有着落

- 快捷添加时可选择今天、明天或暂不安排。
- 支持编辑、完成、归档、删除，以及搜索、筛选和手动排序。
- 为任务设置截止时间、提醒、优先级、标签、备注与子任务。
- 支持日 / 周 / 月重复任务，完成后生成下一条。
- 筛出逾期和待安排任务，一键安排到今天或明天。

### 在日历里看清安排

- 月、周、日三种视图，同时显示任务与日历事件。
- 点击日期添加安排；事件支持时间段、全天、颜色、地点、备注、重复和提醒。
- 任务与普通事件可通过日期选择器改期，也可在月 / 周视图中拖动把手到目标日期。
- 改期时保留时间或时长，关联提醒随之移动。

### 数据留在自己手里

- 桌面版使用 SQLite 保存任务、事件和设置，重启后保留。
- 支持 JSON 导出与导入，方便手动备份或迁移。
- 导入前预览内容；同 ID 记录保留本机版本，重复导入不增加副本。
- 不需要云端账号；目前没有云同步功能。

## 开始使用

### 获取应用

当前可通过下方步骤从源码运行。安装包发布后，将放在 [Releases](https://github.com/Chao163709/daydrop/releases) 页面。

| 平台 | 当前状态 |
| --- | --- |
| Windows | 已生成 EXE / MSI 安装包；完整安装流程及部分系统功能待实机验收 |
| macOS | 已有相关实现，尚未实机验证或提供安装包 |
| 浏览器 | 可预览任务、日历与外观；不提供原生桌面功能 |

### 日常操作

1. 启动桌面版后，悬停或点击日期圆点展开面板。
2. 在快捷输入框记录任务，选择今天、明天或暂不安排。
3. 打开「日历」查看安排，点击日期添加事件，或拖动条目右侧把手改期。
4. 在「设置」中调整展开方式、外观、快捷键和提醒，并导出备份。

默认全局快捷键为 **Alt + Space**。若与系统或其他软件冲突，可在设置中改为其他组合，例如 **Ctrl + Shift + D**。

关闭窗口会隐藏到托盘；彻底退出请使用托盘菜单或设置中的退出操作。**隐藏后仍可提醒，完全退出后不会发送通知。**

## 本地开发

### 环境准备

- **Node.js 24+** 与 npm（测试使用 Node.js 内置 SQLite）。
- 桌面版另需 **Rust stable 1.90+**。
- Windows：MSVC 工具链、Visual Studio C++ 构建工具与 WebView2。
- macOS：Xcode Command Line Tools。

桌面环境安装步骤见 [Tauri 官方前置要求](https://v2.tauri.app/start/prerequisites/)。

### 克隆与安装

```bash
git clone https://github.com/Chao163709/daydrop.git
cd daydrop
npm ci
```

### 运行桌面版

```bash
npm run desktop:dev
```

### 浏览器预览

```bash
npm run dev
```

打开 [http://127.0.0.1:1420/](http://127.0.0.1:1420/)。

浏览器预览使用 localStorage，与桌面版 SQLite 数据相互独立。托盘、全局快捷键、开机自启等功能需要在桌面版中使用。

### 检查与构建

```bash
# TypeScript 检查与前端生产构建
npm run build

# 任务、日历、设置、提醒与备份逻辑测试
npm test

# Rust 原生测试（需要桌面构建环境）
npm run desktop:test

# 构建桌面应用及安装包
npm run desktop:build
```

Windows 安装包输出目录：

- EXE：`src-tauri/target/release/bundle/nsis/`
- MSI：`src-tauri/target/release/bundle/msi/`

首次桌面构建需要下载 Rust 依赖及打包工具，请确保网络可用。打包工具缓存在 `src-tauri/target/.tauri/`；清理 `target` 后需要重新下载。

## 技术与结构

**Tauri 2 · React 19 · TypeScript · Vite · Tailwind CSS 4 · Zustand · SQLite**

日期处理使用 date-fns，动画使用 Framer Motion，图标使用 lucide-react。

```text
src/
  components/       任务、日历、设置、备份与基础 UI
  hooks/            浮窗交互、外观与桌面集成
  lib/              数据仓储、日期逻辑、提醒与备份
  store/            Zustand 状态管理
  App.tsx           应用入口界面
  styles.css        主题与样式
src-tauri/
  src/              原生窗口、托盘、快捷键、通知与备份
  migrations/       SQLite 数据库迁移
  capabilities/     桌面权限配置
scripts/            开发入口与测试脚本
```

数据库包含 `tasks`、`events`、`settings` 三张表。Windows 桌面数据位于应用配置目录 `%APPDATA%\com.daydrop.desktop`，数据库名为 `daydrop.db`。迁移数据建议使用设置中的 JSON 导出 / 导入。

## 当前限制

- 项目处于早期开发阶段。Windows 托盘、快捷键冲突、开机自启、通知投递及部分原生交互仍需完整实机验证；macOS 尚未实测。
- 重复事件按整个系列编辑和删除，暂不支持只修改某一次；拖动改期仅支持任务与非重复事件。
- 提醒依赖应用运行。启动或休眠恢复时会补发最近 24 小时内的到期提醒，更早的提醒不会补发。
- 暂不支持云同步、多人协作或第三方日历同步。
